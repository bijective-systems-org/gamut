# Gamut examples

Start with [First file](https://bijective-systems-org.github.io/gamut/first-file.html).
Each starter program writes `first.gamut` and reads back three lift coefficients.

| Language | Program |
|---|---|
| Python | [00_readme.py](00_readme.py) |
| MATLAB | [sweep.m](matlab/sweep.m) |
| Julia | [sweep.jl](julia/sweep.jl) |
| C++ | [sweep.cpp](cpp/sweep.cpp) |
| Rust | [sweep.rs](rust/sweep.rs) |

Run each program in a fresh working directory. The
[example guide](https://bijective-systems-org.github.io/gamut/guide/index.html)
covers run status, meshes, time series and models.
